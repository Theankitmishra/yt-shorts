Quick Setup:
1. In Google Cloud Console, enable YouTube Data API v3 and create an OAuth Client ID (Web application) with Redirect URI: http://127.0.0.1:8765/api/youtube/callback.
2. Under Google Auth Platform → Audience → Test users, add the exact Gmail address you sign into YouTube with *(prevents Error 403: access_denied)*.
3. Paste your downloaded client_secret.json below → click Save OAuth Client → Connect YouTube Channel.
